# MonkeySharp

Interpreter and compiler in C# following the books by Thorsten Ball

## Overview

MonkeySharp is a C# implementation of the Monkey programming language, inspired by the books "Writing An Interpreter In
Go" and "Writing A Compiler In Go" by Thorsten Ball. This project aims to provide a clear and concise implementation of
both an interpreter and a compiler for the Monkey language, making it easier for developers to understand the concepts
of language design and implementation.
